# **App Name**: PDFinder

## Core Features:

- PDF Listing: Display a list of PDF documents fetched from Supabase database. Each item should show the document name and a preview.
- Global Search: Implement a search bar at the top of the main display to filter PDFs by name and keywords.  Use Supabase's search capabilities to efficiently query the documents.
- PDF Viewer: When a user selects a PDF from the list, display the PDF content.  The PDF viewer should support zoom and standard navigation.
- Offline Download: Add an option to download the PDF for offline access. Store downloaded PDFs in the device's cache memory.
- In-Document Search: Implement a search bar within the PDF viewer to search for specific text inside the currently opened document.

## Style Guidelines:

- Primary color: White for a clean and professional look.
- Secondary color: Light gray for backgrounds and subtle accents.
- Accent: Teal (#008080) for the search bar, download icons, and other interactive elements.
- Use a clean and simple layout with a top search bar and a list of PDF documents below.
- Use cards to display the PDF documents in the main listing.
- Use clear and recognizable icons for actions like download, search, and navigation.
